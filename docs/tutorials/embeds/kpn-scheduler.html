A Kahn Process Network you can schedule

The network from the lecture. f sends even numbers up and odd numbers down, each g passes tokens through, and h takes one token from the top, then one from the bottom, in turn. Every read blocks until a token arrives. Fire the processes in any order you like: the output never changes.
